# Кладоискатель для Годвилля 1.25.1

Расширение для Godville и Erinome. Новое в этой версии:

- «Проверить рядом»: отдельная рекомендация одного соседнего хода. Учитывает кандидатов, в том числе условные термо, неизвестных соседей и соседство ловушки. Это экспериментальная местная эвристика, не оптимальный маршрут до клада и не гарантия безопасности. Команды игре не отправляет. На прыгучих картах совет отключён.
- Ручной тип «Аквариум»: отключает геометрические бонусы, номера на карте и топ-3; показывает список кандидатов без приоритета. Автоматически режим включается только по текстовому признаку, не по одному отсутствию стен.
- Тип выбирается для каждого этажа отдельно. Старые настройки, сохранённые для похода целиком, не переносятся автоматически: выберите тип этажа заново.
- Условные термокандидаты сохраняются с прежними весами и явной подписью «Условно». Совместимость с указателями не означает доказанный клад.
- Кадры без номера шага остаются в хранилище, но не включаются в последовательный экспорт V1/V2, если есть кадры с номерами. V2 сообщает omittedUnknownFrames. Это предотвращает сброс найденного клада поздним кадром перемотки. Если все кадры без номеров, они экспортируются как раньше.
- Изменение номера этажа вызывает пересчёт, а не только изменение карты и шага.

## Установка и обновление

Распакуйте ZIP. Если расширение загружено как распакованное, замените файлы в его прежней папке и нажмите «Обновить»/«Перезагрузить» на странице расширений, затем перезагрузите вкладку Godville. Для установки из ZIP используйте способ импорта, доступный в вашем браузере Lemur. Не запускайте одновременно две версии кладоискателя.

Расширение использует разметку карт Godville/Erinome. Разрешения и список сайтов сохранены от 1.24.1. Новый ключ расширения не создавался; идентичность распакованной установки сохраняйте использованием прежней папки.

## Проверка

`node tests/regression.cjs` и `node --check content.js` проходят. Проверены условный соседний кандидат на ситуации шага 32 из 3508j2er0, запрет совета через стену/абсолютный туман, отключение при завершении и прыгучести, равенство геометрических вариантов в аквариуме, экспорт после кадра перемотки, раздельные ключи этажей и изменение сигнатуры после стены/ловушки/смены этажа.

Это модульные проверки на воспроизведённых ситуациях, не полный прогон всех хроник. Визуальная проверка в Chromium и проверка на телефоне не выполнены: тестовый браузер не удалось загрузить. Улучшение процента попаданий и экономия ходов пока не измерены.

Тайные комнаты не добавлены в расчёт. Числовые веса обычных подземелий не изменены по одному контрпримеру. Определение авторского происхождения конкретного этажа по одной хронике остаётся ограниченным; используйте ручной выбор.

## Исправление 1.25.1

Принудительный перенос строк в совете направления, пояснении указателей, источнике и статусе типа этажа. Устранено наследование nowrap от мобильного сайта. Логика рекомендаций не менялась. Проверка внешнего вида на реальном Android остаётся за пользователем.
